🚀 How to deploy the Higgsfield Proxy
STEP 1 — GitHub (2 min)
1. Go to github.com/new
2. Create repo named higgsfield-proxy
3. Upload the 3 files from the proxy package:
  → server.js   package.json   railway.json
STEP 2 — Railway (3 min)
1. Go to railway.app → Sign up (free)
2. Click New Project → Deploy from GitHub repo
3. Select higgsfield-proxy
4. Railway auto-detects Node.js and deploys ✓
STEP 3 — Environment Variables
In Railway → your project → Variables tab:

HF_KEY = your-higgsfield-api-key HF_SECRET = your-higgsfield-secret
Click Deploy after adding variables
STEP 4 — Get your Proxy URL
Railway → project → Settings → Domains
Copy URL, looks like:
https://higgsfield-proxy-production.up.railway.app
STEP 5 — Paste into Scanner
Paste the Railway URL into the Proxy URL field above → Save.
The Send to Higgsfield button now works end-to-end. ✓

💰 Cost: Railway Hobby ~$5/month. Proxy uses minimal resources.
